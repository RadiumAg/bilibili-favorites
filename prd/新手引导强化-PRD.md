## 1. 背景与问题

### 1.1 背景

近期收到用户反馈：**"插件功能看不懂、用不明白"**。现有引导体系仅包含：

- Popup 内 4 步高亮式 Tour（`src/popup/components/tourist/`），仅在收藏夹数据加载成功后首次自动触发；
- "通过标签整理"按钮上的 `?` Popover 说明；
- 未登录时的全屏提示页（`LoginCheck`）；
- Popup 顶部"查看使用方式"按钮（重放 Tour）。

### 1.2 问题诊断（根因分析）

| # | 问题 | 具体表现 | 严重度 |
| --- | --- | --- | --- |
| P1 | 核心流程概念链过长 | 完成一次"一键整理"需先理解：默认收藏夹 → 标签 → 标题匹配 → 自动移动，共 4 个概念 | 高 |
| P2 | 关键交互不可发现 | "长按收藏夹设为默认"是隐藏交互，Tour 中仅文字带过，用户无法自行发现 | 高 |
| P3 | 引导与流程脱节 | Tour 只解释"区域是什么"，不带领用户实际走通一次完整流程 | 高 |
| P4 | 前置条件缺失无提示 | 未设默认收藏夹 / 无标签时点击"通过标签整理"，结果为移动 0 个视频，用户误以为功能故障 | 高 |
| P5 | 空状态不指路 | 标签区、收藏夹区为空时，没有告诉用户"下一步该做什么" | 中 |
| P6 | Options 页零引导 | 标签管理器、AI 配置、拖拽管理页无任何引导 | 中 |
| P7 | 错误提示不指路 | Toast 只报错，不提供"怎么办"的后续动作 | 低 |

### 1.3 核心使用路径（目标路径）

```
登录 B 站 → 打开插件 → 设置默认收藏夹 → 生成标签 → 一键整理 → 视频自动归类
```

本 PRD 的所有设计围绕"让任意新用户在 3 分钟内独立走通上述路径"展开。

## 2. 目标与成功指标

### 2.1 产品目标

1. 新用户无需阅读文档即可独立完成首次整理（首次成功整理率显著提升）；
2. 消除"长按设置默认收藏夹"这一隐藏交互带来的流失；
3. 操作失败时用户能明确知道原因和下一步动作。

### 2.2 成功指标

| 指标 | 当前基线 | 目标 |
| --- | --- | --- |
| 新用户首次打开后 7 日内完成一次"标签整理"的比例 | 未知（需先埋点） | ≥ 60% |
| 新手任务清单完成率（走完 4 步任务） | — | ≥ 70% |
| "用不明白"类反馈数量 | 现有反馈量 | 下降 ≥ 50% |
| 设置默认收藏夹的用户比例 | 未知 | ≥ 80% |

> 指标依赖第 6 节的数据埋点方案落地后才可度量。

## 4. 功能需求

> 优先级定义：P0 = 本期必做；P1 = 本期尽量做；P2 = 可顺延至下一期。
>
> ⚠️ 流程约束：按 AGENTS.md 规范，下述所有涉及新组件 / 大幅 UI 调整的需求，实现前必须先通过 `ui-ux-pro-max` 技能产出视觉设计方案并经确认。

### 4.1 【P0】F1：任务式新手引导（Onboarding Checklist）

**目标**：把现有"讲解式 Tour"升级为"任务式引导"，带用户真实走通一次完整流程。

#### 4.1.1 任务清单定义

| 步骤 | 任务 | 完成判定条件 | 引导方式 |
| --- | --- | --- | --- |
| T1 | 登录 B 站 | cookie 校验通过（复用 `useCookieFromChrome`） | 已有 `LoginCheck`，登录成功后自动勾选 |
| T2 | 设置默认收藏夹 | `defaultFavoriteId` 非空 | 高亮收藏夹区域，提示"长按或点击星标设置默认"，**等待用户真实完成**后进入下一步 |
| T3 | 生成标签 | `keyword` 数组中存在至少 1 条记录 | 引导点击"自动创建标签"，完成后自动勾选 |
| T4 | 完成首次整理 | 任意一次"通过标签整理"或"AI 分类"执行且移动数 > 0 | 引导点击"通过标签整理"，成功后播放完成动画并结束引导 |

#### 4.1.2 交互规则

1. **触发时机**：用户已登录且 `favoriteData` 加载成功、任务清单未完成时自动展示；
2. **展示形态**：Popup 顶部可折叠的任务卡片（含 4 个步骤的状态：未开始 / 进行中 / 已完成），不阻断正常操作，可手动收起；
3. **可续做**：每步完成状态持久化（见 6.2），中途关闭 Popup 后下次打开继续；
4. **可跳过**：提供"跳过引导"入口，跳过后写入完成标记，不再自动弹出；
5. **可重开**：现有 `?` 按钮保留，点击后除重放 Tour 外，也可重新打开任务卡片；
6. **完成庆祝**：T4 完成后展示一次轻量庆祝效果（复用现有 `finished-animate` 组件风格），并露出"了解更多功能"入口（指向文档站 Guide 章节）。

#### 4.1.3 边界情况

- 用户收藏夹总数为 1（无法"移动到别的收藏夹"）：T2-T4 仍展示，但 T4 文案改为"体验 AI 智能分类"，引导走 AI 分类路径；
- 用户手动完成了某步（未经引导）：下次打开时该步自动标记完成；
- 侧边栏（SidePanel）复用 Popup 组件，任务卡片同样生效，注意宽度自适应。

#### 4.1.4 与现有 Tourist 的关系

- 保留现有高亮 Tour 作为"界面认知"层，任务卡片作为"行为达成"层；
- 首次进入顺序：任务卡片出现 → 用户点击某任务时，按需触发对应步骤的高亮定位（复用 Tourist 的高亮遮罩能力，扩展为单步模式）。

### 4.2 【P0】F2：默认收藏夹交互显性化

**目标**：消除"长按才能设置默认收藏夹"这一不可发现的交互。

#### 4.2.1 需求明细

1. **显性入口**：收藏夹卡片 hover 时显示"设为默认"星标按钮（`Star` 图标），点击即设置默认收藏夹；长按交互保留作为快捷方式（兼容老用户）；
2. **默认态标识**：已设为默认的收藏夹常驻显示实心星标 + "默认"角标，视觉上与普通收藏夹明确区分；
3. **引导联动**：任务卡片 T2 步骤高亮时，星标按钮需带呼吸/脉冲动画提示。

#### 4.2.2 涉及改动点（技术侧参考）

- `src/components/favorite-tag/`：卡片增加星标按钮与默认角标；
- `src/hooks/use-set-default-fav/`：复用现有设置默认逻辑；
- Tour 步骤 2 的文案同步更新（不再只说"长按"）。

---

### 4.3 【P0】F3：关键操作前置条件检查

**目标**：点击"通过标签整理"等操作前，检查前置条件，缺失时引导补齐而非静默执行。

#### 4.3.1 检查规则

| 操作 | 前置条件 | 缺失时行为 |
| --- | --- | --- |
| 通过标签整理 | ① 已设默认收藏夹 ② 存在至少 1 个标签 | 弹引导 Dialog，说明缺失项并提供对应操作按钮（"去设置默认收藏夹"/"去生成标签"） |
| AI 智能分类 | ① 已设默认收藏夹 ② AI 配额可用或已配置自定义 AI | 同上，指向 AI 配置页（`options.html?tab=setting`） |

#### 4.3.2 交互规则

1. Dialog 使用现有 `AlertDialog` / `Dialog` 组件，文案友好、不使用报错口吻；
2. 引导按钮点击后：设置默认收藏夹 → 关闭 Dialog 并高亮收藏夹区域（触发 T2 定位）；生成标签 → 打开标签管理器页；
3. 前置条件满足时，操作行为与现状完全一致，不引入额外交互。

---

### 4.4 【P1】F4：空状态行动指引

**目标**：空状态不再只是一张图，而是明确告诉用户下一步做什么。

| 位置 | 当前状态 | 目标状态 |
| --- | --- | --- |
| 标签区为空 | 无引导 | 显示"还没有标签？"文案 + 「一键自动生成标签」按钮 |
| 未设默认收藏夹 | 无提示 | 收藏夹区顶部显示一条可关闭的提示横幅："设置默认收藏夹后，可一键自动归类其中的视频" + 「去了解」 |
| 收藏夹列表为空 | 依赖 B 站数据 | 提示"登录 B 站并收藏视频后，这里会显示你的收藏夹" |

- 横幅的关闭状态持久化，每个端只提示一次；
- 任务清单进行中时，横幅与任务卡片二选一显示，避免引导堆叠。

---

### 4.5 【P1】F5：错误提示带出路

**目标**：关键失败场景的 Toast 附带后续动作。

| 错误场景 | 当前提示 | 增强后 |
| --- | --- | --- |
| 未获取到 B 站登录信息 | 仅报错 | Toast 附带「查看解决方法」→ 打开文档 troubleshooting 对应章节 |
| AI 配额不足 | 仅报错 | 附带「配置自己的 AI」→ 打开 AI 配置页 |
| WebDAV 同步失败 | 仅报错 | 附带「检查连接配置」→ 打开云同步配置页 |

- 复用现有 `toast` 组件，扩展 `action` 字段（标题 + 跳转 URL）；
- 文档 URL 指向 doc 站点对应页面（release 后为线上地址，开发期可用相对路径占位，实现时确认）。

---

### 4.6 【P2】F6：Options 页上下文帮助

**目标**：为 Options 三个高频页面补充轻量引导。

1. **标签管理器**：首次进入显示提示条（可关闭、状态持久化）："标签用于自动归类：视频标题包含标签关键词时，会被移动到对应收藏夹"；
2. **AI 配置页**：免费额度与自定义模式两个选项旁增加说明文案和推荐标识（新用户推荐免费额度）；
3. **拖拽管理页**：首次进入显示一步提示："左侧选择收藏夹，右侧可多选/拖拽视频到其他收藏夹"。

- 统一使用可关闭提示条（InfoBar）组件，样式与 B 站风格一致（主色 `#00AEEC`）。

## 5. 非功能需求

1. **无障碍**：新增按钮、任务卡片需支持键盘导航与 `aria-label`；提示横幅可关闭且关闭控件可聚焦；
2. **性能**：任务卡片状态检查不得在每次渲染时读取 chrome.storage，需缓存到内存（Zustand 或组件 state）；
3. **多端一致**：Popup（384px 宽）与 SidePanel（宽度可变）下任务卡片均需正常展示，任务卡片最大高度受限，超出滚动；
4. **代码规范**：遵循 AGENTS.md —— 回调统一 `useMemoizedFn`、禁止 `void` 忽略返回值、新组件先过 `ui-ux-pro-max` 设计流程；
5. **兼容**：老用户（已完成旧版 Tour）不强制进入新任务引导，但可通过 `?` 按钮主动打开。

## 6. 数据与埋点设计

### 6.1 埋点原则

- 全部本地存储，不上传任何用户数据（与 PRIVACY.md 一致）；
- 仅记录"是否完成/是否点击"，不记录内容数据。

### 6.2 存储 Key 设计（chrome.storage.local）

| Key | 类型 | 说明 |
| --- | --- | --- |
| `onboarding_task_status` | `{ t1: boolean, t2: boolean, t3: boolean, t4: boolean }` | 任务完成状态 |
| `onboarding_skipped` | `boolean` | 是否跳过引导 |
| `onboarding_completed_at` | `number` | 引导完成时间戳 |
| `hint_banner_dismissed` | `{ defaultFavBanner: boolean, keywordEmpty: boolean }` | 横幅关闭状态 |
| `options_tip_dismissed` | `{ keywordManager: boolean, aiConfig: boolean, dragManager: boolean }` | Options 提示条关闭状态 |

### 6.3 需统计的关键漏斗（本地计数，供后续版本决策）

1. 引导曝光 → 各任务步骤完成数；
2. 前置条件 Dialog 曝光 → 引导按钮点击数；
3. 错误 Toast 曝光 → 「查看解决方法」点击数。
