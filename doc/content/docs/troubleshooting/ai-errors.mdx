本页覆盖与 **AI 相关** 的错误。非 AI 的批量失败请看 [批量操作失败](/docs/troubleshooting/batch-operation)。

## AI 功能的两种模式

扩展的 AI 功能只使用你在配置页填写的 **自定义 AI**：`baseUrl` + `apiKey` + `model`。v1.2.18 起不再提供内置免费 AI / AIGate 路由。

## 未配置 / 配置不完整

<Callout type="warn">
  点击「🤖 AI 整理」时，扩展会先校验 **API Key、模型名称和 Base URL**。配置不完整时会提示先完成 AI 配置，并引导回配置页。
</Callout>

处理办法：回到配置页，按 [API Key 配置](/docs/configuration/api-key) 填完服务商、模型、API Key 和 Base URL。

## AI 返回的数据格式错误

<Callout type="warn">
  Toast 标题 **「整理失败」**，描述 **「AI 返回的数据格式错误，请重试」**，详情区会带上 AI 返回的原始文本。
</Callout>

扩展期望 AI 的响应中至少包含一段 `\[...\]` 形式的 JSON 数组；若匹配失败则进入这个分支。

常见原因：

- 模型输出夹杂了 Markdown 代码块包裹但解析逻辑无法识别；
- 模型返回了自然语言解释，没有返回 JSON；
- 模型被上游网关截断（例如命中 `max_tokens` 限制）；
- 使用了思考模式（`thinking` / `reasoning`）导致内容前置了思考文本。

排查建议：

<Steps>
  <Step>
    ### 查看详情区的原始返回
    Toast 详情里包含完整 AI 文本。若明显被截断（结尾停在一半），见下一步；若完全没有 JSON，见「换模型」。
  </Step>
  <Step>
    ### 针对思考模式做降级
    在配置页选择内置适配器时，扩展会自动把 `extraParams` 里的思考模式关闭；若你用的是 **自定义** 适配器，请手动在 `Extra Params` 中加入关闭思考的字段（如 `{"chat_template_kwargs":{"enable_thinking":false}}` 或 `{"thinking":{"type":"disabled"}}`），具体 key 取决于你对接的后端。
  </Step>
  <Step>
    ### 换一个模型
    重试仍失败时，切换到能力更强的模型（如 `qwen-plus` / `glm-4-plus` / `gpt-4o`），通常能解决。
  </Step>
</Steps>

## 请求失败 / 网络错误

典型表现：Toast 标题 **「整理失败」**，描述是底层请求抛出的错误信息。

| 错误信息关键字 | 可能原因 | 解决方式 |
|----------------|----------|----------|
| `401` / `Unauthorized` | API Key 错误或已吊销 | 在服务商后台重新生成 Key 并更新配置 |
| `403` / `Forbidden` | 模型无权限 / 地区限制 | 对照服务商文档确认模型可用性 |
| `404` / `Not Found` | Base URL 拼写错误或少了 `/v1` | 回到配置页，重新选择适配器（会覆盖为官方默认 Base URL）|
| `429` / `Rate limit` | 触发服务商限流 | 等待几分钟后重试，或升级套餐 |
| `Network error` / `Failed to fetch` | 扩展无法访问 API 端点 | 见下方「host_permissions 相关」|

### host_permissions 相关

扩展 Manifest 的固定 `host_permissions` 只保留 Bilibili、OpenAI 与讯飞域名；其他自定义地址属于可选站点权限范围。若你使用自定义 Base URL（如 `api.deepseek.com`、`dashscope.aliyuncs.com`、`api.moonshot.ai`、`open.bigmodel.cn`）：

- 扩展内置适配器实际通过 **background service worker 的 fetch** 调用；大部分情况下请求能正常发出；
- 若遇到浏览器或企业策略拦截，可能表现为 `Failed to fetch`；
- 处理方法：在扩展详情页检查该自定义站点的访问权限与网络请求日志。

## 用户取消

遮罩层的 **「取消」** 按钮会：

- 中止 AI 的流式读取；
- 中止后续的移动接口调用；
- Toast 提示 **「已取消」** / **「操作已取消」**。

已经移动成功的视频 **不会被回滚**。
